# 新增八款设备的验证范围

验证日期：2026-10-03。产品字段与枚举均核对各产品自身的公开物模型，
状态来源为设备所有者账号下的动态状态查询。未包含完整物模型、账号、设备标识或日志。

| 产品 | 能力 | 实测范围 |
| --- | --- | --- |
| 20I0 欧普台灯 Pro | 电源、亮度 3–255、色温 3000–5000 K、模式 | 在线状态；开/关、亮度改为 40、模式切换均收到设备状态确认，原状态已恢复。色温写入待单独验证 |
| 2J6Y 达伦台灯3i | 总电源、主灯、指示灯、亮度、模式、渐灭延时、夜灯、灯光状态 | 在线状态；总开/关、亮度改为 40、模式切换均收到设备状态确认，原状态已恢复。其它控制待验证 |
| A0OP 酷宅墙壁开关 | 单路开关 | 离线影子状态；写命令仅离线测试，待设备上线实测 |
| A2LW 酷宅温湿度传感器 | 只读温度、湿度 | 离线影子值按物模型单位读取，没有自行添加倍率 |
| A3G6 美的冰箱 | 冷冻/冷藏设定温度、速冻/速冷、故障 | 在线状态与故障枚举；命令仅离线测试，未改变冰箱设置 |
| A08G 美的风扇 | 只读电源、模式、风速原值、摇头 | 离线影子；实机 5600117P 的 fan.speed 与物模型 FTS30-16BR 的 fan.gear 不符，不提供控制 |
| V0D5 华为智慧屏 S86 | 只读屏幕、音量、亮度、静音、输入源等 | 离线影子；未验证局域网控制，不声明动作 |
| V0DE 华为 Vision 智慧屏 3 | 同上 | 同上 |

离线影子是最后一次上报，不代表当前物理状态。电视仅输出明确列出的状态字段，
不输出 remotecontrol 中的凭据，也不套用另一型号的图像模式码。冰箱速冷/速冻是模式，
不命名为电源。A08G 的风速 5 不会被限幅成物模型的 1–4 档。

`profile_fields.py` 只为单品适配器显式选定的字段提供读写辅助，不自动扫描或适配未知产品。
`vision_states.py` 只被两款已核对状态结构的智慧屏调用。

离线验证命令：

```sh
python -m unittest discover -s tests -p test_household_adapters.py -v
```

11 项测试使用最小合成字段片段，覆盖数值边界、非法值/未知状态、夜灯同服务字段保留、
只读权限、产品字段差异及敏感字段排除。控制命令尚未全部完成真机验证，因此先以草稿 PR 提交。
